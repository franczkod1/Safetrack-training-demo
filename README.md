# SafeTrack training demo

Standalone browser-based presentation prototype for multilingual workplace training management.

## Demo

The site is published with GitHub Pages from the `main` branch.

## Scope

- Fictional test data only
- Presentation prototype, not a production system
- Fully separate from the Handyreparatur-Lippe project

## Mandatory project documents

- `PROJECT_RULES.md` contains the release and validation rules that must be followed for every future change.
- `INCIDENT_2026-08-05_KPI_DEPLOYMENT.md` records the dashboard-card deployment error, its root cause, and the preventive actions.

## Release requirement

A feature may only be reported as working after the exact deployed artifact has been tested through the public GitHub Pages URL and the expected end-to-end state change has been verified.
